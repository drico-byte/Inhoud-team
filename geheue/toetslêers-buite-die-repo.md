Never save a one-off or test file inside the repository folder. Use the scratchpad.

**Why:** On 5 Oct 2026 I saved a Grade 8 maths HTML test page in `interaktief/`. A parallel Gr 7 LO session committed the whole folder and pushed it to GitHub. Lampies: "This project is all about content writing, not html file creation." Erasing it would have meant a force push across three PCs ([[drie-rekenaars-werk-parallel]]), so it stays in the history.

**How to apply:** Anything that isn't pipeline content goes to the scratchpad, and gets sent to the user from there. Assume that anything in the repo folder will be committed by another session within minutes.
