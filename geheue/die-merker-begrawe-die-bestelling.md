The marker that demotes superseded spec text to record — `[OORTREFDE TEKS
HIERONDER…]` — is the fix for a corrected opening with an unmarked tail. Set one
line too high it causes the mirror fault: **the field, read literally, orders
nothing.**

11 September 2026. A coverage check found it in electricity lesson 1: only the
"stelsel" sentence was superseded, the marker covered the whole remainder, and
the block's purpose — the parts carrying the stored energy to where it is needed,
with light *and* heat at the lamp — had no live instruction, while the budget
still paid about 75 words for it and the sub-topic's answer plan still leaned on
it.

**Why it is dangerous rather than untidy:** coverage tests against `kern`. A
requirement below the marker cannot fail a draft, so the next revision can drop
the block and no check objects. The current draft looks fine, which is why it
survives.

**How to apply.** Sweeping all 111 marked fields for "every ordering verb sits
below the marker" gave 27 hits, of which seven were real — so read each one; the
count is not the finding. Repair by **restating the order above the marker** and
adding a line saying exactly what the marker covers ("DIE MERKER HIERONDER DEK
NET …"). One field was already correct because someone had written that line by
hand.

**22 September 2026: four variants in one day, all in one subject, all caught by
coverage checkers and none by my sweeps.**

1. The correction goes into the fact-risk note and the requirement keeps ordering the
   old form. (Five times.)
2. The record bracket **permits**: "that sentence is in itself RIGHT and MAY STAY",
   with a source cited. "Right", "may stay" and a citation read as instruction however
   far down a field they sit.
3. Two dated brackets in one field, **same date**, the withdrawn form standing last, so
   nothing tells a reader which wins.
4. The withdrawal stands FIRST and the original imperative continues **outside** the
   bracket, flat and unmarked, standing last — "KEEP the comparison, change only the
   arrangement" — while the bracket one sentence earlier says it was cut. That bracket
   even named the mechanism and then left the order standing.

**The test that catches all four, and a wording sweep catches none of them: read the
field from the BOTTOM UP and ask what the last imperative sentence tells a writer to
do.** A writer reads a field as prose, and the last order wins. If the last order is
not the one I intend, the field is broken however correct its opening line is.
