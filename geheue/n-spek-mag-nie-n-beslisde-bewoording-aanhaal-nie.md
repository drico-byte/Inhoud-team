Gr 6 Social Sciences, Democracy, 1 October 2026. One ruling moved four shared
wordings in a day. Every spec field that had **quoted** one of those wordings
became an order for the withdrawn form — and a writer reading such a field
top-down rebuilds exactly what was just withdrawn, and can cite the field for
it.

It happened in three fields, and in one of them for the **second time**: lesson
4's requirement for what a right is had already been caught once ordering a
closed list of sources after a fact check opened it, and the reason was the same
both times — it quoted the entry verbatim.

**Why:** a decided wording lives in one file per subject-grade and is injected
into every extract, so it is always current where an agent reads it. A copy of
it inside a spec field is not injected and nothing refreshes it. The spec's job
is to say *what the lesson must do*; the wording's job is to say *how it is
said*. Quoting collapses the two and makes every ruling a sweep.

**How to apply.** A spec field orders the **shape** and defers the sentence:
which sources must be named, that the list must read as open, which words are
already taken by another decided term, which lessons define the term and which
do not. Then one line telling the writer to read the sentence itself from the
injected list of decided wordings, and not from the field. Where a record has to
quote an old form so a reader can see the history, say in the same breath that
it is not the decided form and must not be written.

The symptom to watch for: a field that *describes* the target wording ("the new
form adds …"). That description is a quotation wearing a different coat, and it
goes stale the same way. See
[[die-ooreengekome-bewoording-kan-self-verkeerd-wees]] for why these wordings
move so often, [[die-korrigeerde-opdrag-bly-in-die-veld-staan]] and
[[n-nota-wat-n-toestand-vasvries-verouder]] for the wider family, and
[[vee-die-bewering-oor-al-die-spesifikasies]] for the sweep a moved ruling needs.
