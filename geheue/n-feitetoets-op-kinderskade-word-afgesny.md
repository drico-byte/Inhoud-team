**1 October 2026.** The fact check on a Grade 6 lesson about children's rights
was terminated by a content filter the moment it turned to the governing
statute's definitions of kinds of harm to children. It had written **no report**,
so the entire check was lost.

**Why:** nothing about the task is improper — it is an accuracy check on a
published-curriculum school lesson — but verifying those entries pulled it into
generating long stretches of explicit statutory text, which it never needed in
order to answer the narrow question.

**How to apply.** Two things in the brief, and the second one is general:

1. **Verify by citation, not by reproduction.** Ask for the verdict, the specific
   distinction tested, and the provision checked against; a short quotation where
   one word is decisive, never the definition in full. Ask for a plain, clinical
   register throughout.
2. **Tell every long check to write its report early and update it as it goes.**
   A partial report on disk beats a complete one that never got saved. This is
   worth doing for any long agent run, not only ones at risk of a filter.

Expect this wherever a lesson is about harm, safety or abuse — which is a large
part of Life Skills in every grade. Check for a written file before concluding
nothing happened: see [[n-agent-wat-faal-kan-sy-werk-klaar-he]], and
[[veiligheidslesse-lewer-die-ergste-foute]] for why these checks matter most.
